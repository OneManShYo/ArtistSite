## SUMMARY

V1.10.0 adds a **Learn** page — a curated listing of the videos, references, people, companies, and communities behind the work, reachable from the last tab in the main nav. Built entirely on the existing design system (cyan panel headers, standard link styling), so it looks and behaves like the rest of the site.

---

## WHAT'S NEW

### Learn Page
A new **Learn** tab (last item in the nav) opens a references page: a short intro, an Inspiration section (People, Companies, Communities), a Videos list, and an Other Material list of papers and docs — each entry linking out to the source. Closes with a `PLUR` sign-off.

The page carries the reference set over from the Chippy app and re-skins it to the Artist Site design system: cyan section headers, cyan links, consistent panel cards.
