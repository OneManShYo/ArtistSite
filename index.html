ONEMANSHYO Dojo

About

ONEMANSHYO Dojo is an electronic music performance surface combining DJ mixing and live reactive visual mixing. Think of it as a one-person audio/visual show — live DJ set with real-time generated visuals that react to the music.

The custom app runs entirely in Chrome using WebGPU for shader rendering, Web Audio API for analysis and mixing, and the File System Access API for persistent library management. Zero installation. Single HTML file.

App Features

CREATE — Author WGSL fragment shaders with real-time preview, audio-reactive modulators (bass/mid/treble), FFT analysis, transform controls, and BumpR StickRs video overlays.
ORGANIZE — Library management with tagging, smart sets, search, and metadata editing. Containers package shader + audio + settings into portable .oms files.
PERFORM — 4-track mixer with 8 scenes, per-track EQ3, DJ FX, VFX, cue points, DSP compression, and quantized launching. Output composites to a pop-out window for live projection.
ADMIN — Audio card routing, camera/PIP configuration, BumpR StickRs management, effect pool assignments.

Technical

Optimized for Chrome on MacBook Pro 14". Uses WebGPU for 60fps shader rendering across 4 simultaneous tracks, with real-time audio analysis driving visual reactivity through bandpass-filtered peak detection with ADSR envelopes.

Yomatics

About

Yomatics explores cymatics — making sound vibrations visible. Water and materials react to electronic dance music frequencies in real-time, creating visual patterns that reveal the physical nature of sound.

Different frequencies create different geometric patterns. Bass frequencies produce large, slow-moving waves. Higher frequencies create intricate, detailed structures. The result is a direct, physical visualization of music.

The History of Visuals in Ableton Live

A chronological timeline of native visuals in Ableton Live Suite

Summary

Yo team, this is a walk through the history of visuals in Ableton Live, from the Max and Jitter roots starting in 1997 up to October 2026. I went back through my videos and reference material to trace how native visuals in Live came together: Cycling '74's Max and the Jitter visuals add on, QuickTime video arriving in Live 6, Max for Live in 2009, Vizzie, Ableton acquiring Cycling '74, and Max for Live shipping inside Live Suite starting with version 10.

Along the way: Robert Henke on Max being built for things with no timeline and Live being built around one, which is still the core thing to figure out when you tie visuals to music. Early Max for Live experiments, community tutorials from Amazing Max Stuff, Ned Rush, and others, TDAbleton for TouchDesigner, and devices you can still pick up today, including EboSuite, Videosync, T3X2R, Ganz Graf Mod X, Geometrum 02, and Photism, through to Max 9 and the 9.2 release. Worth knowing: even though Ableton owns Cycling '74, the two run on separate roadmaps, so a new Max release like 9.2 doesn't ship with Live Suite right away.
